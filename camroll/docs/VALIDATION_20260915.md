## 真实接入与故障恢复

- 北京业务空间实测通过文本、图片＋JSON Schema、原生 Function Calling 往返及云端流式响应。请求与响应模型均固定 Qwen3.7-Flash；明确关闭 thinking。
- WeMM 新接口实测返回归一化 4096 维文本/图片向量；中文分块无损，超长查询明确报错。接口使用现有认证及本机访问限制，模型只提供资产 ID。
- 建库期间外部任务曾停止 WeMM 并占用 GPU 1。未控制该外部进程；通过独立 `enrich` 保存云端进度，资源持有方恢复 WeMM 后继续编码。
- 334 张图片编码耗时约 **112.67 秒**。汇合发布时复用 334 个图片编码、333 个 caption 和333项事件阶段缓存，不重复已成功的云端工作。
- 首轮 M4 暴露本地引用校验过严：正文举例一张，证据列表列出支持整体总结的五张，均已传入模型，却因集合不完全相等被拒绝。已修正为正文引用必须是已复核且已声明证据的子集；越界引用仍拒绝。保留初次失败及复现记录，修复后在新目录重跑验证。
- 最终四种组合均通过 search、view、来源引用、最终模式检查；M2/M4 的实际 Qwen 请求携带指定图片。HTTP 普通问答和 M4 SSE 均通过。每种模式仅为少量接口检查，不是最终答案评分。

## 使用与后续优先级

在 `.100` 项目目录运行：

```bash
.venv/bin/python deployment/with_config.py camroll_agent ask \
  '照片中有哪些动物？' --memory runtime/albums/photobench-album3 --config M1 --json
```

Mac 可建立 `ssh -N -L 8770:127.0.0.1:8770 realmagic@192.168.0.100`，再调用本机接口：

```bash
curl http://127.0.0.1:8770/api/ask -H 'Content-Type: application/json' \
  -d '{"album_id":"photobench-album3","question":"照片中有哪些动物？","config":"M1"}'
```

P0/P1 已实施，P2 作为开关保留；P3/P4 见 [实现与升级矩阵](IMPLEMENTATION.md)。后续优先考虑独立验证：限制事件摘要长度减少首建云端耗时、API层批量提交减少空闲轮询等待、用新验证集研究双路融合。当前本地排名约2毫秒，无需优先增加 ANN 或向量数据库。局部裁剪、多跳、人脸/OCR/重排模型均未引入。
