## 先验证发布物

从Release下载源码包、`source-manifest.json`与`SHA256SUMS`，运行`sha256sum -c SHA256SUMS`（Mac可用`shasum -a 256 -c SHA256SUMS`）。解包到新空目录；清单的`files`逐项记录相对路径、SHA256、字节数及Git mode。也可使用新目录检出标签`architecture/2026-10-15-v1`。不要把旧标签移动到新提交，不直接覆盖当前运行目录。

```python
import hashlib, json
from pathlib import Path
root = Path("/path/to/extracted/source")
manifest = json.loads(Path("source-manifest.json").read_text())
for item in manifest["files"]:
    data = (root / item["path"]).read_bytes()
    assert len(data) == item["bytes"]
    assert hashlib.sha256(data).hexdigest() == item["sha256"], item["path"]
print("source verified", len(manifest["files"]))
```
