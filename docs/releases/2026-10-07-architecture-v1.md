## 包含的系统范围

- WeMM：后端 API、内部 embedding 接口、串行单模型 worker、encoder、预处理、前端、来源锁，以及独立保存的非权重模型架构源码。
- CamRoll：图片导入、EXIF／地名／CPU身份、描述与事件、图片／文本向量、FTS、不可变索引与模型配置绑定。
- 检索：WeMM 4096维和Qwen 2048维路径，query／document角色，分块、过滤、M4融合、Qwen图片／事件重排及遥测。
- 问答：六工具Agent、看图、最终复核、规则／事实Gate、四次有界修复、实际模型记录、费用预留和请求journal。
- 评测：冻结协议、题内多轮、Doubao最终质量／行为评分、固定分母指标、执行资格、独立续测与来源校验。
- 页面及运维：8773问答、8774只读报告、Qwen 18778 worker、隔离配置、GPU1所有权／租约／恢复、组件与部署回归。

架构细节见 [ARCHITECTURE_CURRENT](../ARCHITECTURE_CURRENT.md)，模块入口见 [CODE_MAP](../CODE_MAP.md)。历史 `docs/project/`、旧基线标签和恢复资料均保留，当前 README 不再把它们当作最新配置。
