## 2026-09-14 PhotoBench

运行 ID：20260914-115425。证据根目录：[实验交付目录](/Users/zhanyiqi/Documents/nx/wemm-embedding-lab/reports/photobench/20260914-115425)。

固定 A 原问题、B 语义改写、C 关键词；共享媒体索引、模型与评分器，无 router、重排、OCR、caption、身份识别或元数据过滤。只编码媒体内容，QA、答案和文件名没有作为语义输入参与索引。

### 样本与口径

- 344 个源媒体：334 图片、10 视频；352 单元：334 图片、18 视频片段。
- 图片主测 800 题，在全部 334 图片中检索。
- 混合补测 859 题，在全部 344 媒体中检索：800 图片目标、20 混合目标、39 视频目标。
- 5 条缺少 expected_action 的正向问题单列；303 条澄清/拒答/注入题排除并保留理由。
- 864 个不同正向问题，三组 × (800+859+5) = 4992 条逐题结果。主测与补测有题目重叠，不能当成 4992 个独立问题。
- 按 SHA256 合并同内容别名；所有目标可解析。每次取 Top-50，视频按源视频最高片段得分聚合。
- Hit@K：至少一个目标命中；宏 Recall@K：逐题目标命中比例再平均；全部目标覆盖率@K：全部已标注目标均在 Top-K 的题目比例；MRR@50：首个目标倒数排名，50 名外计零。
- 失败在固定分母按零计，同时提供共同成功题配对结果。本轮查询失败和改写失败均为 0。
- 差值区间使用事件分组 bootstrap，2000 次，种子 20260914；图片 225 事件、混合 241 事件。

### 收益、退化与解释边界

原问题应保留为默认输入：固定 B/C 没有改善总体图片召回，并降低首位命中。向量检索前不必强制加入关键词提取或 router。

- 61 条图片事件总结题，B Hit@10 从 91.80% 升至 95.08%，但 Hit@1 从 68.85% 降至 65.57%。不能只挑改善指标。
- 550 条事实题总体无收益；90 条枚举题 C Hit@10 从 98.89% 降至 95.56%。
- 39 条视频目标题，A/B/C Hit@10 为 21/39、22/39、27/39；关键词有探索性收益，但 C Hit@1 仍与 A 相同，仅 9/39。
- 20 条混合目标题各组 Hit@10 都为 100%，但 Recall@10 仅约 52.15%/52.00%/56.42%，说明“至少命中一项”掩盖多证据漏召回。
- 混合总体 C Recall@10 增加约 0.858 个百分点，区间 [-0.282,+2.109] 包含零。
- 有 11 条图片题目标数超过 10，混合有 23 条超过 10；这些题不可能在 Top-10 覆盖全部目标。

私人姓名/身份对应、精确拍摄日期/GPS、跨事件顺序等需要可信元数据或身份能力支持；单靠可见内容向量不能保证。此轮没有测试添加这些能力后的收益。改写也不保证语义无损，审计保留了丢失“国庆节”等条件的实例。
